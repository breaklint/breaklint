# Source provenance

This candidate imports existing Breaklint public client source into a new,
independent repository. The import commit records extraction and release hardening;
it does not assert original authorship of all files. Existing copyright comments
and third-party license notices are retained. Owner confirmation of Breaklint
copyright attribution and repository-wide licensing is required before publication.

The Unicode case-fold table identifies Unicode 13.0.0 and generation through Python
in its original comment. The exact historical generation inputs were not present;
confirm those inputs and applicable terms before public distribution. The current
Unicode permission notice is retained in Unicode-License.txt, obtained from
https://www.unicode.org/license.txt. No historical provenance has been invented.
